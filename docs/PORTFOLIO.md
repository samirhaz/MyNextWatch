## LinkedIn project description

MyNextWatch is a personal space for tracking movies and television shows. It combines a private watchlist and library, 1–10 ratings, notes, season/episode progress, custom collections, and optional sharing links that owners can revoke.

I built the application with Next.js App Router, strict TypeScript, Tailwind CSS, shadcn/ui, Auth.js, Prisma, and MySQL. TMDB powers discovery, metadata, and regional streaming availability. The project includes an isolated interactive demo, server-side ownership validation, database constraints, and automated tests for privacy, persistence, and core user flows.

The architecture is deliberately small enough to explain and maintain: one application, one database, and clearly separated UI, validation, service, and third-party API modules.
